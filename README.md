# 弈境 · 中国象棋

独立静态网页游戏，无服务端依赖。提供同屏双人、三档本地 AI、四道一着将杀残局、37 个杀法与得子教学局，以及 6 门开局教学。支持悔棋、建议落子、翻转棋盘、吃子动画、合成音效、棋谱导出和本机自动存档，适配手机与桌面。

## 本地运行

```sh
python3 -m http.server 4173 --directory .
```

在项目根目录运行上述命令，然后打开 http://127.0.0.1:4173/dist/ 。需要 Python 3 提供 HTTP 服务，以启用 AI Web Worker；无需安装前端依赖。

- 杀法大全：http://127.0.0.1:4173/dist/kills.html
- 开局教学：http://127.0.0.1:4173/dist/openings.html

## 验证

```sh
node tests/rules.test.cjs
node tests/strength.test.cjs
node tests/kills.test.cjs
node tests/openings.test.cjs
node tests/performance.cjs
```

测试包含开局每方 44 着与两层 1920 局面、马腿/象眼/炮架/过河兵/九宫/照面/解将规则、四道残局将杀与三档 AI 合法着法。

AI 使用迭代加深、PVS / Alpha-Beta、置换表、杀手着法与历史排序、晚着缩减及吃子静态搜索（被将军时搜索全部应将）。局面评分考虑子力、过河兵、马的活动空间与车炮开放线路。入门／进阶／高手的搜索上限分别为 3／7／10 层，时间预算约 0.4／1.8／3.5 秒，实际深度随局面和设备变化；新用户默认高手。游戏对三次重复局面判和，不包含正式比赛长将长捉裁定。双人模式为同屏，未包含远程联网匹配。

源码：dist/index.html、style.css、app.js、engine.js、worker.js。所有画面、字体回退及音效均不依赖第三方资源。

## 吃子与将军反馈

每步短暂显示起点、虚线箭头与终点指向，约 1 秒后淡出，1.4 秒内消失；刷新和悔棋不重放线路。吃子使用朱红线路；被吃棋子在落子到达后闪退，显示冲击波与吃子文字。棋盘下方和棋谱保留被吃棋子信息。

将军时棋盘中央显示提示，受攻击的帅／将持续红色高亮，直到解将。AI 应手前留出反馈展示时间。悔棋、重开会清理未完成的动画与延时动作；系统减少动态效果偏好下保留文字和静态高亮。

独立交互测试页（不修改正常游戏存档）：`/tests/feedback-preview.html`，以及 `?case=capture`、`?case=ai`，需从项目根目录启动 HTTP 服务。

棋盘上下各有常驻的「已吃棋子」展示区，按棋子种类显示数量与总枚数。仅统计本局实际吃子；翻转随棋手换位、悔棋同步撤回、刷新从棋谱恢复，重开清空。

## 杀法大全

`/dist/kills.html` 提供 30 个一着杀教学局和 5 个完整多步连杀教学局，支持名称／别名搜索、五类筛选、提示、答案演示、重试和独立解题进度。一着杀允许任何合法将杀着法；多步练习沿已验证主线训练，玩家走红方、黑方自动应将，走完才记为独立解出。看过提示或答案不计为独立解出。学习进度使用独立存储键，不修改对局存档。

运行 `node tests/kills.test.cjs` 检查所有教学局的初始合法性、棋子数量及示范将杀。术语参考链接在学习页页脚，练习局及讲解为本项目编写。

杀法扩充：高钓马保留 `high` 标识，兼容原侧面虎学习记录；新增八角马、送佛归殿、闷杀、三子归边、双车胁士、夹车炮。其中连续进攻型杀法的练习明确标为“收官一着”。

新增列马车（立马车／勒马车）、臣压君、炮碾丹砂（收官一着）、车炮联杀，共 30 式。新增局面均检查合法将杀，并验证列马车撤去护马后黑将可以吃车，确保示例体现马护车的关键。

## 多步连杀与双方演示

新增双车错连将赶底、送佛归殿三进兵、列马车跳马封门、重炮进兵逼将、三子归边炮赶车杀，共 35 个教学局。多步课含双方 3 或 5 手，每一步附说明；所有黑方应着均验证为唯一合法应将。筛选“多步连杀”即可集中练习。

演示支持上一手、下一手、自动播放／暂停、点击着法跳转、从头练习。回退从独立棋盘快照恢复，切课、重试和手动翻步会取消旧定时动作。`study-line.js` 统一生成双方着法与棋盘快照；`node tests/kills.test.cjs` 验证全部 35 局逐手合法、连续将军、黑方应将完整性和最终将杀。

## 战术动画与得子练习

现共 37 个教学局：原有 35 局加上将军抽车、打死车两套 3 手得子战术。得子练习单独筛选，以安全吃车为完成条件，不显示将杀；打死车展示进车分支，并用规则测试验证其余平将、退车分支仍会安全丢车。

所有落子增加短暂线路；闷杀、铁门栓、卧槽马突出炮架、堵门、牵制与马腿，将军抽车显示双重攻击，打死车显示炮线与保护。马按马腿路径运动，吃子显示棋子消失、冲击圈与被吃名称。特效约 1.8 秒自动清除，提供“重播本手动画”，切课、重试、暂停和回退均清除特效；尊重系统减少动态效果偏好。

`study-effects.js` 管理独立特效层，`tests/kills.test.cjs` 验证 37 局及两个得车战术所有防守分支后的安全吃车，浏览器通过隔离存储的 `tests/kills-preview.html` 验证交互。

## 开局教学

`/dist/openings.html` 新增六门完整初始局面课程：中炮对屏风马、顺炮直车对横车、中炮对反宫马、飞相局、仙人指路对卒底炮、起马局。每课演示五回合（双方十手），附每手讲解、布局思路、常见误区及后续计划。课程为自编合法教学变化，不宣称唯一或必胜应法；术语参考在页面页脚。

支持搜索、体系筛选、逐手前进／回退、自动播放／暂停、重播、棋谱跳转，以及选择执红或执黑跟练。跟练沿本课主线，其他合法着法提示“与示例不同”；对方自动走示例应着。只有完成所选方全部五步且未用提示才记录独立完成。观看演示不计跟练进度，重新开始可独立尝试。进度使用 `yijing-openings-v1`，不覆盖对局或杀法存档。

`node tests/openings.test.cjs` 验证六课共六十手的合法性、初始快照、中文记谱及关键阵形。`tests/openings-preview.html` 使用隔离存储做浏览器交互验证。
