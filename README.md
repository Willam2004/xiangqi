# 弈境 · 中国象棋

独立静态网页游戏，无服务端依赖。提供同屏双人、三档本地 AI、四道一着将杀残局；支持悔棋、建议落子、翻转棋盘、合成音效、棋谱导出和本机自动存档。手机与桌面自适应。

## 本地运行

```sh
python3 -m http.server 4173 --directory dist
```

打开 http://127.0.0.1:4173 。需要 HTTP 服务以启用 AI Web Worker。

## 验证

```sh
node tests/rules.test.cjs
```

测试包含开局每方 44 着与两层 1920 局面、马腿/象眼/炮架/过河兵/九宫/照面/解将规则、四道残局将杀与三档 AI 合法着法。

AI 使用迭代加深、Alpha-Beta 和吃子静态搜索。游戏对三次重复局面判和，不包含正式比赛长将长捉裁定。双人模式为同屏，未包含远程联网匹配。

源码：dist/index.html、style.css、app.js、engine.js、worker.js。所有画面、字体回退及音效均不依赖第三方资源。

## 吃子与将军反馈

每步保留起点、虚线箭头与终点指向，吃子使用朱红线路；被吃棋子在落子到达后闪退，显示冲击波与吃子文字。棋盘下方和棋谱保留被吃棋子信息。

将军时棋盘中央显示提示，受攻击的帅／将持续红色高亮，直到解将。AI 应手前留出反馈展示时间。悔棋、重开会清理未完成的动画与延时动作；系统减少动态效果偏好下保留文字和静态高亮。

独立交互测试页（不修改正常游戏存档）：`/tests/feedback-preview.html`，以及 `?case=capture`、`?case=ai`，需从项目根目录启动 HTTP 服务。
